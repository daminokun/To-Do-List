# To-Do List App

A minimalist, responsive task management application built with core web technologies. Designed for quick daily task tracking and clean user interaction.

---

## Live Demo
Access the live application:
https://daminokun.github.io/To-Do-List/

---

## Features
- Task Creation: Add new tasks dynamically to the list.
- Task Completion: Toggle completion status by clicking on task items.
- Task Deletion: Remove tasks instantly from the interface.
- Responsive Interface: Optimized layout for both desktop and mobile viewports.

---

## Tech Stack
- HTML5: Semantic structure.
- CSS3: Custom styling and layout design.
- JavaScript (ES6+): DOM manipulation and interactivity.

---

## Local Setup

1. Clone the repository:
   git clone https://github.com/daminokun/To-Do-List.git

2. Navigate to the project directory:
   cd To-Do-List

3. Run the app:
   Open index.html in any modern web browser.
